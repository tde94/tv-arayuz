# tv-arayuz

Samsung Tizen TV için minimal, karanlık temalı ana ekran. [TizenBrew](https://github.com/reisxd/TizenBrew) uygulama modülü olarak çalışır.

- Saat, tarih ve hava durumu (Open-Meteo)
- Netflix, YouTube, PlayStation (HDMI geçişi), Prime Video, Disney+, Spotify, Internet, SmartThings kısayolları
- Kumandanın ok tuşları ve OK ile gezinme

## Kurulum

TizenBrew → Module Manager → modül ekle: `gh/tde94/tv-arayuz`

Ayarlar `app/config.js` içinde.
